# Services

AEM Component for displaying a list of services with icons, headlines, and descriptions.

## Configuration

This component can be configured through the following tabs:

### Content
- **Component Title**: Enter the component title text (displayed as H2)
- **Service Items**: List of service items (each item has:
  - Service Icon (SVG): Select an SVG icon from DAM
  - Service Headline: Enter the service headline text (displayed as H3)
  - Service Description: Enter the service description text

### Style Options
- **Apply background color**: When checked, a background color will be applied to the services section.

## Usage

This component can be added to AEM pages through the component console. 
Configure the fields according to the tab structure above to customize the component's appearance and behavior.
