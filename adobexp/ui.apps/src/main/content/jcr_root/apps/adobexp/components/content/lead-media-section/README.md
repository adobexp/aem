# Lead Media Section

AEM Component for displaying a section with title, description, media (image or video) and a CTA button.

## Configuration

This component can be configured through the following tabs:

### Content
- **Title**: The main headline text for the section
- **Description**: The description text that appears below the title

### Media
- **Media Type**: Select whether to display an image or video
- **Image**: Select an image from DAM to display in the media frame
- **Image Alt Text**: Alternative text for the image (for accessibility)
- **Video**: Select a video file (MP4, WebM, etc.) from DAM. Video will auto-play when visible.
- **Video Start Time (seconds)**: Time in seconds to skip at the beginning of the video (e.g., 0.5, 1, 2)

### CTA Button
- **CTA Button Text**: Text displayed on the CTA button (e.g., 'Try for Free', 'Learn More')
- **CTA Link**: URL for the CTA button. Can be internal page path or external URL.
- **Open in new tab**: Open the CTA link in a new browser tab

### Icon Badge
- **Icon Badge Type**: Select the icon style for the badge (Arrow, Play, Image, Video)

### Style Options
- **Media Alignment**: Position of the media relative to the content
- **Apply Background Color**: Apply a background color to the section

## Usage

This component can be added to AEM pages through the component console. 
Configure the fields according to the tab structure above to customize the component's appearance and behavior.
