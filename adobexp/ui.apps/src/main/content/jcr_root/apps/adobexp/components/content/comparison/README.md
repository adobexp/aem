# Comparison

AEM Component for displaying a comparison grid with three columns.

## Configuration

This component can be configured through the following tabs:

### General
- **Section Title**: Main title displayed above the comparison grid (e.g., 'Process')

### Column 1
- **Heading Number**: Optional number displayed before the heading (e.g., '01')
- **Title**: Column heading title
- **Description**: Short description text below the title
- **List Items**: List of items for this column (each item has text field)

### Column 2
- **Heading Number**: Optional number displayed before the heading (e.g., '02')
- **Title**: Column heading title
- **Description**: Short description text below the title
- **List Items**: List of items for this column (each item has text field)

### Column 3
- **Heading Number**: Optional number displayed before the heading (e.g., '03')
- **Title**: Column heading title
- **Description**: Short description text below the title
- **List Items**: List of items for this column (each item has text field)

### Style Options
- **Apply Background Color**: Apply a background color to the comparison section

## Usage

This component can be added to AEM pages through the component console. 
Configure the fields according to the tab structure above to customize the component's appearance and behavior.
