# Video

AEM Component for displaying a video with teaser overlay.

## Configuration

This component can be configured through the following tabs:

### Video Settings
- **Video**: Select video file from DAM
- **Show Play/Pause Button**: Check to show the play/pause button on the video
- **Show Mute/Unmute Button**: Check to show the mute/unmute button on the video
- **Show Fullscreen Button**: Check to show the fullscreen button on the video

### Teaser Overlay
- **Video Title**: Title displayed on the teaser overlay
- **Video Description**: Description displayed on the teaser overlay
- **Teaser Link**: Select a content page from /content or enter an absolute URL (including protocol, e.g., https://example.com)
- **Open in New Tab**: Check to open the link in a new tab

## Usage

This component can be added to AEM pages through the component console. 
Configure the fields according to the tab structure above to customize the component's appearance and behavior.
