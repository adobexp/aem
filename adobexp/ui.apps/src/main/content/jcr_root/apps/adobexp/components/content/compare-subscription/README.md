# Compare Subscription

AEM Component for comparing subscription plans.

## Configuration

This component can be configured through the following tabs:

### Plan 1
- **Plan Name**: Name of the first subscription plan
- **Monthly Price**: Monthly price for the first plan
- **Show Most Popular badge**: Show a "Most Popular" badge for this plan
- **Show Best Value badge**: Show a "Best Value" badge for this plan
- **Highlight this plan**: Highlight this plan in the comparison
- **Plan Features**: List of features for this plan (each feature has a title and an "Included" checkbox)

### Plan 2
- **Plan Name**: Name of the second subscription plan
- **Monthly Price**: Monthly price for the second plan
- **Show Most Popular badge**: Show a "Most Popular" badge for this plan
- **Show Best Value badge**: Show a "Best Value" badge for this plan
- **Highlight this plan**: Highlight this plan in the comparison
- **Plan Features**: List of features for this plan (each feature has a title and an "Included" checkbox)

### Plan 3
- **Plan Name**: Name of the third subscription plan
- **Monthly Price**: Monthly price for the third plan
- **Show Most Popular badge**: Show a "Most Popular" badge for this plan
- **Show Best Value badge**: Show a "Best Value" badge for this plan
- **Highlight this plan**: Highlight this plan in the comparison
- **Plan Features**: List of features for this plan (each feature has a title and an "Included" checkbox)

### Plan 4
- **Plan Name**: Name of the fourth subscription plan
- **Monthly Price**: Monthly price for the fourth plan
- **Show Most Popular badge**: Show a "Most Popular" badge for this plan
- **Show Best Value badge**: Show a "Best Value" badge for this plan
- **Highlight this plan**: Highlight this plan in the comparison
- **Plan Features**: List of features for this plan (each feature has a title and an "Included" checkbox)

### Common Settings
- **Component Title**: Title text for the component
- **Component Description**: Description text for the component
- **Currency Symbol**: Currency symbol to display with prices (default: $)
- **Apply Background Color**: Apply a background color to the section

## Usage

This component can be added to AEM pages through the component console. 
Configure the fields according to the tab structure above to customize the component's appearance and behavior.
