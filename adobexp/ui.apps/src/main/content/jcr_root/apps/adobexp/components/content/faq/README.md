# FAQ

AEM Component for displaying frequently asked questions with expandable answers.

## Configuration

This component can be configured through the following tabs:

### Content
- **Section Title**: Enter the FAQ section title (e.g., 'Frequently Asked Questions')
- **FAQ Items**: List of FAQ items
  - **Question**: Enter the FAQ question
  - **Answer**: Enter the FAQ answer (supports rich text formatting)
  - **Expanded by Default**: Expand this item by default when the page loads

### Style Options
- **Apply Background Color**: Apply a background color to the FAQ section

## Usage

This component can be added to AEM pages through the component console. 
Configure the fields according to the tab structure above to customize the component's appearance and behavior.
