# Quote

AEM Component for displaying a quote with author information.

## Configuration

This component can be configured through the following tabs:

### Content
- **Component Title**: Enter the component title text (e.g., 'Quote')
- **Primary Quote Text**: Enter the main quote text
- **Muted Quote Text**: Enter the secondary/muted quote text (displayed in lighter color)

### Author
- **Author Avatar (SVG)**: Select an SVG avatar from DAM. If not provided, a default avatar will be displayed.
- **Author Name**: Enter the author's name
- **Author Organisation**: Enter the author's organisation or company name

## Usage

This component can be added to AEM pages through the component console. 
Configure the fields according to the tab structure above to customize the component's appearance and behavior.
