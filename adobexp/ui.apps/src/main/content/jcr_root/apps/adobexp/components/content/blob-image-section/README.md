# Blob Image Section

AEM Component for displaying content with a blob-shaped image/video container.

## Configuration

This component can be configured through the following tabs:

### Content
- **Badge Title**: Text displayed in the badge area (e.g., 'WHO WE ARE', 'VIDEO DEMO')
- **Main Title**: The main headline text for the section
- **Description**: The description text that appears below the title

### Primary Media
- **Media Type**: Select the type of media to display in the blob-shaped container (Image or Video)
- **Image**: Select an image from DAM to display in the blob-shaped container
- **Image Alt Text**: Alternative text for the image (for accessibility)
- **Video**: Select a video file (MP4, WebM, etc.) from DAM. Video will auto-play when visible.
- **Video Alt Text**: Alternative text for the video (for accessibility)
- **Video Start Time (seconds)**: Time in seconds to skip at the beginning of the video (e.g., 0.5, 1, 2)

### CTA Button
- **CTA Link**: URL for the CTA button. Can be internal page path or external URL.
- **CTA Button Text**: Text displayed on the CTA button (e.g., 'Start creating', 'Learn more')
- **Open in new tab**: Open the CTA link in a new browser tab
- **CTA Position**: Position of the CTA button overlay on the image

### Overlay Elements
#### Overlay Image
- **Overlay Image**: Select a circular overlay image from DAM
- **Overlay Image Alt Text**: Alternative text for the overlay image
- **Overlay Image Position**: Position of the overlay image

#### Overlay Card
- **Overlay Card Image**: Select an image for the overlay card from DAM
- **Overlay Card Title**: Title text for the overlay card (e.g., 'New York')
- **Overlay Card Subtitle**: Subtitle text for the overlay card (e.g., '253 Broadway')
- **Overlay Card Position**: Position of the overlay card

### Icon Badge
- **Icon Badge Image**: Select an icon image (SVG recommended) from DAM for the badge overlay
- **Icon Badge Alt Text**: Alternative text for the icon badge (for accessibility)
- **Icon Badge Position**: Position of the icon badge on the image

### Style Options
- **Shape Pattern**: Select the clip-path shape pattern for the image/video container
- **Image Alignment**: Position of the image/video relative to the content
- **Apply Background Color**: Apply a background color to the section
- **Apply Card Background**: Apply a background color to the card container

## Usage

This component can be added to AEM pages through the component console. 
Configure the fields according to the tab structure above to customize the component's appearance and behavior.
