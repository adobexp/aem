# Looping Circle Gallery

AEM Component for displaying a circular gallery with rotating images and an overlay message.

## Configuration

This component can be configured through the following tabs:

### Gallery Settings
- **Gallery Message**: The overlay message displayed in the center of the gallery (e.g., 'Crafting memorable brands by creating lasting impressions...')

### Gallery Images
- **Gallery Images (8 images recommended)**: List of images for the circular gallery (each image has:
  - Image: Select an image from the DAM
  - Alt Text: Alternative text for the image (for accessibility)

## Usage

This component can be added to AEM pages through the component console. 
Configure the fields according to the tab structure above to customize the component's appearance and behavior.
