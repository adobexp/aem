# Call To Action

AEM Component for a call-to-action section with title, subtitle, and primary/secondary CTAs.

## Configuration

This component can be configured through the following tabs:

### General
- **Title**: Main CTA headline
- **Subtitle**: Supporting text below the title
- **Apply Background Color**: Apply a background color to the CTA section

### CTA
- **Primary CTA Text**: Label for the primary pill button
- **Primary CTA Link**: Link path for the primary CTA
- **Open in new tab** (primary): Opens the primary CTA in a new tab
- **Secondary CTA Text**: Label for the secondary button
- **Secondary CTA Link**: Link path for the secondary CTA
- **Open in new tab** (secondary): Opens the secondary CTA in a new tab

## Usage

Add this component to AEM pages through the component browser under **Adobe XP Components - Content**. Theme (dark/light) is controlled by the page template.
