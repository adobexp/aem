# Subscription Plans

AEM Component for displaying subscription plans with pricing, features, and CTA buttons.

## Configuration

This component can be configured through the following tabs:

### Plan 1
- **Plan Name**: Name of the first subscription plan
- **Monthly Price**: Monthly price for the first plan
- **Yearly Original Price**: Original yearly price for the first plan
- **Yearly Price**: Yearly price for the first plan
- **Discount Until**: Discount end date for the first plan
- **CTA Text**: Text for the CTA button on the first plan
- **CTA Link**: URL for the CTA button on the first plan
- **Open CTA in new tab**: Open the CTA link in a new browser tab
- **Show Top Choice badge**: Show a "Top Choice" badge for this plan
- **Show Special Offer badge**: Show a "Special Offer" badge for this plan
- **Credits Value**: Value for credits associated with this plan
- **Credits Unit**: Unit for credits associated with this plan
- **Credits Label**: Label for credits associated with this plan
- **Plan Features**: List of features for this plan

### Common Settings
- **Component Title**: Title text for the component
- **Component Description**: Description text for the component
- **Default Billing**: Default billing cycle (Monthly or Yearly)
- **Yearly Discount Text**: Text to display for yearly discount (e.g., "SAVE 33%")
- **Currency Symbol**: Currency symbol to display with prices (default: $)
- **Monthly Billing Note**: Text to display for monthly billing
- **Yearly Billing Note**: Text to display for yearly billing
- **Apply Background Color**: Apply a background color to the section

## Usage

This component can be added to AEM pages through the component console. 
Configure the fields according to the tab structure above to customize the component's appearance and behavior.
