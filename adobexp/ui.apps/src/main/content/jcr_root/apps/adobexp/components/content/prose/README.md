# Prose

AEM Component for long-form rich text content blocks with scroll-reveal animation.

## Configuration

This component can be configured through the following tabs:

### General
- **Content Blocks**: Multifield of rich text blocks. Each block renders as a separate `.prose__block` with HTML formatting (headings, lists, links, etc.).

## Usage

Add this component to AEM pages through the component browser under **Adobe XP Components - Content**. Theme (dark/light) is controlled by the page template.
