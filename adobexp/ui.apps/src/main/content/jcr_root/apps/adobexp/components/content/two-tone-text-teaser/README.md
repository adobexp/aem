# Two Tone Text Teaser

AEM Component for displaying text with two different color tones and a CTA button.

## Configuration

This component can be configured through the following tabs:

### Content
- **Primary Text**: Enter the primary text (displayed in primary color)
- **Secondary Text**: Enter the secondary text (displayed in secondary color)

### CTA
- **CTA Text**: Enter the call-to-action button text
- **CTA Link**: Select the target page or enter external URL
- **External Link**: Check if the CTA link is an external URL (opens in new tab)

## Usage

This component can be added to AEM pages through the component console. 
Configure the fields according to the tab structure above to customize the component's appearance and behavior.
