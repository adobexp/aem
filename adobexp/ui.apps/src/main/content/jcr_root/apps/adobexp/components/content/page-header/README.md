# Page Header

AEM Component for an interior page header with title and subtitle.

## Configuration

This component can be configured through the following tabs:

### General
- **Title**: Page header title (H1)
- **Subtitle**: Supporting text below the title

## Usage

Add this component to AEM pages through the component browser under **Adobe XP Components - Content**. Theme (dark/light) is controlled by the page template. Animation is CSS-only.
