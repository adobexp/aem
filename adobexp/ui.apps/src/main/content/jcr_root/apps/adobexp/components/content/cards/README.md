# Cards

AEM Component for a feature card grid with configurable columns and scroll-reveal animation.

## Configuration

This component can be configured through the following tabs:

### General
- **Title**: Section title above the card grid
- **Subtitle**: Supporting text below the title
- **Grid Columns**: Number of columns (2, 3, or 4; default 3)
- **Apply Background Color**: Apply a background color to the cards section

### Cards
- **Card Items**: Multifield of cards, each with:
  - **Icon**: Emoji or glyph displayed above the card title
  - **Title**: Card heading
  - **Description**: Card body text

## Usage

Add this component to AEM pages through the component browser under **Adobe XP Components - Content**. Theme (dark/light) is controlled by the page template.
